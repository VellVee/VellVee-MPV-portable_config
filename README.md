# MPV Config

A personal, quality-focused [mpv](https://mpv.io/) configuration made for for high-end AMD hardware and 4K HDR displays.

Features automated profile switching.
Includes shaders and scripts.

## Used Shaders
- [ArtCNN](https://github.com/Artoriuz/ArtCNN/releases/)
- [FSR](https://gist.github.com/agyild/82219c545228d70c5604f865ce0b0ce5)
- [SSimSuperRes](https://gist.github.com/igv/2364ffa6e81540f29cb7ab4c9bc05b6b)

## Used Scripts
- [uosc](https://github.com/tomasklaen/uosc)
- [fuzzydir](https://github.com/sibwaf/mpv-scripts/blob/master/fuzzydir.lua)
- [mpv-persist-properties](https://github.com/d87/mpv-persist-properties)
- [autoload](https://github.com/mpv-player/mpv/blob/master/TOOLS/lua/autoload.lua)
- [memo](https://github.com/po5/memo)
- [visualizer](https://github.com/mfcc64/mpv-scripts/blob/master/visualizer.lua)
